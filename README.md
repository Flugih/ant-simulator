# ant-simulator

Учебный проект: симулятор муравья на C# и WPF.

Муравей ходит по полю из белых и чёрных клеток, перекрашивает их и поворачивает по правилам, которые задаёт пользователь.

## Что умеет программа

- задать размер поля (ширина и высота от 10 до 100 клеток)
- настроить правила для белой и для чёрной клетки
- запустить муравья и поставить на паузу
- сгенерировать поле заново
- показывает, сколько шагов сделал муравей

## Как работают правила

Для каждого цвета клетки можно выбрать, что делает муравей:

- Повернуть направо
- Повернуть налево
- Идти прямо

И поставить галочку "Перекрасить клетку", тогда белая клетка станет чёрной, а чёрная белой.

После этого муравей делает шаг вперёд. Если он доходит до края поля, то появляется с другой стороны.

По умолчанию стоят классические правила:

- белая клетка: повернуть направо и перекрасить
- чёрная клетка: повернуть налево и перекрасить

## Как пользоваться

1. Ввести ширину и высоту поля
2. Нажать "Сгенерировать"
3. Выбрать правила
4. Нажать "Запустить"
5. Чтобы остановить муравья, нажать "Пауза"
